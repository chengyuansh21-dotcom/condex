# Condx Request Templates

Use these example requests with `$archrender-optimizer`.

## Default

```text
使用 $archrender-optimizer 优化这张建筑效果图。请保留原建筑体量、相机角度、立面比例、道路和场地关系，只增强材质、灯光、人物、绿化、天空和清晰度。使用 gpt-image-2 生成一版汇报级效果图，并说明保留内容、优化内容和下一步可调整方向。
```

## Premium Commercial

```text
使用 $archrender-optimizer 把这张商业街效果图优化成高端招商展示风格。请用 gpt-image-2，只做克制优化：提升店铺灯光、玻璃反射、铺装质感、人物活动和商业氛围，不要改变建筑造型、窗户位置和街道尺度。
```

## Urban Renewal

```text
使用 $archrender-optimizer 优化这张城市更新街区图。目标是更适合方案汇报：保留老街尺度、建筑高度和道路关系，增强铺装、街具、绿化、日常生活氛围和图像清晰度。不要做成过度商业或梦幻风。
```

## Night Commercial

```text
使用 $archrender-optimizer 将这张商业建筑日景改成夜景汇报图。用 gpt-image-2，保留原透视和立面比例，增加温暖室内光、店铺灯光和适度反射，避免霓虹过度、赛博朋克或电影感过强。
```

## Material Only

```text
使用 $archrender-optimizer 只优化这张图的材质和光影。请不要增加人物、树木、招牌或新物体；保留所有建筑和场地关系，只提升玻璃、石材、金属、混凝土质感、阴影层次和清晰度。
```
